 About This Portfolio

This repository contains my coursework, laboratory exercises, assignments, workshop activities, design artefacts, implementation tasks, testing activities, and project deliverables completed throughout the CMN224 Software Engineering unit at Western Pacific University.

The portfolio serves as a record of my learning progress and demonstrates the practical application of software engineering principles, methodologies, analysis techniques, design modelling, implementation, testing, documentation, and version control practices. Each weekly folder contains evidence of activities completed during the semester and showcases the progressive development of knowledge and skills acquired throughout the course.
